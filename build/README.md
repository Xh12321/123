# PPT 生成脚本

- `build_deck.py`：直接以官方模板 `模板.pptx` 为母版生成 `源代码审计智能体-技术与成果汇报.pptx`
  （26 页，含逐页讲稿备注）。封面与“目录”两页沿用模板原页，仅替换文字；正文页使用模板的 `空白` 版式
  （深蓝底图 + 圆角白底渐变面板）。
- `deck_lib.py`：设计 token（模板主题色：主色 `266ABD`、金色 `DFB865`、正文 `39302A`、字族思源宋体/思源黑体）、
  图元与文本溢出估算工具。
- `render.py`：无 LibreOffice 环境下的近似渲染器（把 PPTX 画成 PNG，用于版式自检）。

重新生成：

```bash
python3 build/build_deck.py     # 生成 PPTX，并输出文本溢出检查报告
python3 build/render.py 源代码审计智能体-技术与成果汇报.pptx   # 输出 PNG 预览到 /tmp/preview
```

> 说明：模板不再需要从 GitHub Release 下载，仓库 `main` 分支的 `模板.pptx` 即官方模板原文件
> （13 页示例、8 个版式）。生成时保留前两页、删除其余示例页，再按四大部分（业务价值与成效 /
> 技术创新性 / 成熟度与稳定性 / 推广复用潜力）插入正文。

## 4 分钟汇报版

```bash
python3 build/make_4min.py    # 从 用户修改版.pptx 抽取 11 页 → 源代码审计智能体-4分钟版.pptx
```

- 保留：封面 / 目录 / 四重困境 / 流水线 / 四项价值 / 创新总览 / 三方辩论 / 成熟度 / CyberGym / 推广路径 / 致谢。
- 同步重排页脚（NN / 11）、修正封面标题字号与副标题位置，并按四分钟重写逐页汇报词（备注带时间戳与秒数预算）。
